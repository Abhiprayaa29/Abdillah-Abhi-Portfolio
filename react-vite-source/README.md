# Abdillah Abhi — Professional Developer Portfolio

React + Vite + Tailwind CSS portfolio built from verified CV information and a review of the public repositories under `Abhiprayaa29`.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Notes

- CV is copied unchanged to `public/cv/Abdillah-Abhi-CV.pdf` for the download/view action.
- Project visuals intentionally use public repository assets for the projects where a repository image is available. Other projects use UI/architecture visualizations instead of fabricated screenshots.
- No live demo buttons are shown because no working deployment was independently verified during the build.
- LinkedIn is not included because it was not verified in the supplied CV/source set.
- Replace the remote repository image URLs with local optimized assets before a high-performance production deployment if desired.

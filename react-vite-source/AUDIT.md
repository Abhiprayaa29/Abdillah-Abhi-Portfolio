## Repository evidence used

### MLBB Draft Studio
- React 18 + Vite + Tailwind CSS v4 + Framer Motion.
- Express + Socket.IO backend with server-authoritative shared state.
- Draft engine separated from UI as pure state-transition functions.
- Match persistence, backups, theme controls, OBS-ready overlay routes, and optional operator token protection are documented/implemented.

### bot_spada
- Python Telegram bot + FastAPI read-only dashboard.
- SPADA login/scraping, semester detection, local tracking, deadline reminders, attendance automation, QR pairing, and dashboard data routes.
- `web/auth.py` uses expiring session cookies; `web/pairing.py` generates QR images; `spada.py` implements the LMS scraper.

### JogjaLensa / ProjectPemogramanWeb-Abdillah-Abhi
- PHP 8 native + Bootstrap 5.3 + MySQL/MariaDB.
- Client/vendor workflows, booking, payment proof, review/rating, invoice, vendor packages and portfolio management are documented in `readme.md` and reflected in `index.php`/project structure.

### SimpleARPlacement
- Unity 6000.3.24f1, AR Foundation 6.5.0, ARCore 6.5.0, URP 17.3.0.
- `ARPlacementManager.cs` implements raycast-based placement, optional anchor attachment, movement, rotation, scale, and reset behavior.
- `ARUIController.cs` connects UI actions to placement controls.
- Repository contains device/UI screenshots under `Docs/SimpleARPlacement/Screenshots/`.

### Cerberus
- Bun-based OpenCode-oriented multi-agent orchestrator.
- README documents intent routing, specialist agents, parallel background agents, category routing, and explicit authorized-use boundaries.
- `cerberus-agent.jsonc` configures agent roles and tool permissions.

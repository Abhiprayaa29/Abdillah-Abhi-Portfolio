# Folder: assets/projects/mlbb/
## MLBB Draft Studio — Broadcast Overlays & Operator Panel

Folder ini berisi aset screenshot untuk proyek **MLBB Draft Studio (Engine Turnamen Esports & Transparent OBS Overlays)**.

### File yang ada saat ini:
- `overlay-draft.webp` : Tampilan transparent OBS Browser Source 1920×1080 saat draft pick/ban berlangsung.
- `overlay-score.webp` : Tampilan broadcast overlay papan skor dan status gold/tower.
- `control-panel-operator.webp` : Antarmuka workstation operator turnamen dengan timer dan status match.
- `control-panel-grid.webp` : Grid seleksi hero esports berkecepatan tinggi.
- `control-panel-tema.webp` : Pengaturan tema grafis tim turnamen.

> File-file ini sudah terhubung lengkap di halaman utama dan modal Case Study MLBB Draft Studio.
